Leonida Legend: an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI (1 platinum, 2 gold, 6 silver, 46 bronze). Each trophy carries its official name, description and grade plus an original guide with named sources; a 5-stage roadmap runs from story chapters through stranger strands, counted activities and collectible sweeps to 100% completion and the platinum; 13 trophies are flagged missable with reasons drawn from the official descriptions. Progress saves in the browser with export and import, filters cover kind and grade plus search, and a spoiler-safe mode hides story trophies until earned. Static files, no build step, works with the network off.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
