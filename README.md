Leonida Legend: an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI (1 platinum, 2 gold, 6 silver, 46 bronze; 28 hidden on PlayStation until earned). Each trophy carries its official name, description and grade plus an original guide — a Where line, prose, and numbered steps — naming three sources with a note on what each one backs. A 5-stage roadmap runs from story chapters through stranger strands, counted activities and collectible sweeps to 100% completion and the platinum, with per-stage progress bars, tappable trophy chips and a Next Up strip; a Missable Watch panel lists all 13 missable trophies with reasons drawn from the official descriptions. The 22 counted trophies carry saved progress counters (351,306 tracked items and dollars) that tick themselves earned at the target. Progress and counters save in the browser with export and import (older v1 files still import), filters cover kind and grade plus search and four sort orders, and a spoiler-safe mode hides story trophies until earned. Static files, no build step, works with the network off.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
