Leonida Legend: an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI. Every trophy with its official name, description, and grade; a 5-stage roadmap to the platinum; missable flags with reasons built from the official descriptions; a guide per trophy in original words with named sources; filters by kind and grade; a spoiler-safe mode that hides story trophies until earned; progress saved in the browser with export and import. Static files, no build step, works with the network off.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
